# 사용법 — who-was-heard (고루듣기)

[English](USAGE.en.md) · [처음으로](../README.md)

이 문서는 도구를 처음 쓰는 사람을 위한 안내다. 설치부터 첫 보고서, 차수 반복, AI 앱 연결, 문제 해결까지 순서대로 적었다.

---

## 1. 준비

| | |
|---|---|
| 운영체제 | 윈도 10·11, 맥OS, 리눅스 |
| 파이썬 | 3.9 이상. 윈도는 [python.org](https://www.python.org/downloads/)에서 받아 설치할 때 **「Add python.exe to PATH」를 꼭 체크**한다 |
| 디스크 | 약 3GB — 패키지 1~2GB, 문장 임베딩 모델 약 1.1GB |
| 메모리 | 8GB 이상 권장. 2만 건이 넘는 자료는 16GB |
| 인터넷 | 처음 한 번(패키지·모델 내려받기)과 「직접 받기」 때만. 분석 자체는 PC 안에서 돈다 |

API 키는 필요 없다. 유튜브·열린국회정보에서 자료를 직접 받을 때만 각자의 키를 쓴다.

## 2. 켜기

저장소를 받아 압축을 푼 뒤(또는 `git clone`):

| | |
|---|---|
| 윈도 | **`start.pyw` 더블클릭** — 검은 창 없이 뒤에서 돈다 |
| 맥 | **`start.command` 더블클릭** — 처음엔 우클릭 → 열기 |
| 어디서나 | `python start.py` — 창에 기록을 보며 돈다(문제를 찾을 때) |

- 브라우저에 **설정 페이지**(`http://127.0.0.1:8730`)가 열린다
- **처음 한 번은 필요한 패키지를 뒤에서 설치**한다(몇 분). 기록은 `_logs/start.log`
- 화면은 PC의 지역 설정에 맞춰 한국어나 영어로 뜨고, 오른쪽 위 버튼으로 바꿀 수 있다
- 끌 때는 설정 페이지의 「**MCP 서버 끄기**」를 두 번 누른다
- 주소는 이 PC 안에서만 열린다. 같은 와이파이의 다른 기기나 인터넷에서는 닿지 않는다

다른 포트를 쓰려면 `python start.py --port 8740`.

## 3. 분석 화면 — 처음부터 끝까지

설정 페이지에서 「**분석하기 →**」를 누르면 **Who Was Heard Analysis** 화면이 열린다(`/studio`). 위에서 아래로 여섯 단계다.

> 이 화면에는 원문이 보인다. 이 PC에서만 열리고, 아무것도 밖으로 나가지 않는다. 화면을 공유할 때는 조심한다.

### 프로젝트

따로 만들지 않아도 된다. ①에서 자료를 넣으면 파일 이름이나 자료 이름으로 프로젝트가 생긴다. 작업은 `문서\who-was-heard\<프로젝트>`에 남는다(자료 사본, 차수별 보고서, 판단 파일, 규칙 파일). 다른 곳에 두려면 환경 변수 `WWH_WORK`로 바꾼다. 「작업 폴더 열기」로 바로 연다.

### 임베딩 모델

글을 숫자(벡터)로 바꾸는 공개 모델이다. 기본은 [`paraphrase-multilingual-mpnet-base-v2`](https://huggingface.co/sentence-transformers/paraphrase-multilingual-mpnet-base-v2)(약 1.1GB, Apache-2.0, 50개 넘는 언어). 첫 1차를 돌릴 때 자동으로 받는다. 「임베딩 모델」 칸에서 미리 받거나, 저장 위치를 바꾸거나(D 드라이브 등), 지울 수 있다.

### ① 자료 넣기

**파일** 탭 — CSV·TSV·XLSX를 올리거나 경로를 적는다. 한 줄이 글 하나(발언·댓글·의견)이고, 글 열과 집단 열(정당·채널·위원회 등)이 있으면 된다.

**직접 받기** 탭 — 자료를 도구가 받아 온다.

| 출처 | 필요한 것 | 메모 |
|---|---|---|
| 미국 의회 회의록 (govinfo) | 기간 | 키 없음, 퍼블릭 도메인. 발언자 이름·정당·주·상하원. 한 번에 92일까지 |
| 국회 회의록 — 국회도서관 데이터셋 | 내려받은 XLSX | [국회도서관 「입법정보」 데이터셋](https://losi-open.nanet.go.kr/user/dataset/datasetList.do?category_cd=2)에서 회의록 XLSX를 받아 올린다. 여러 파일 가능. 기간·위원회·회의 구분으로 거른다. 발언자 칸을 이름·직함·구분(의원 / 국회 사무처 / 정부·기관·증인 등)으로 나눈다 |
| 국회 — 열린국회정보 Open API | 본인 인증키, API 코드 | 회의록 API는 본문 대신 목록만 주는 경우가 있다 |
| Polis 공개 토론 | 대화 이름 | CC BY 4.0. 작성자의 의견 집단과 운영자 처리 결과가 붙는다 |
| 유튜브 댓글 | 본인 YouTube Data API 키, 영상 주소 | 작성자 ID는 받자마자 해시. 받은 댓글은 다시 배포하지 않는다 |
| 유튜브 실시간 채팅 | 본인 키, 지금 방송 중인 영상 주소 | 끝난 방송은 공식 API로 받을 수 없다. 하루 할당량 주의 |
| 주소(URL) | 주소 | CSV·TSV·XLSX·JSON은 표로, 웹 페이지는 문단으로 |

- 국회도서관 XLSX를 **파일 탭에 올려도** 알아보고 「직접 받기 → 국회도서관」 방식으로 자동 변환한다
- 키는 도구가 디스크에 저장하지 않는다. 「이 브라우저에 기억」을 고르면 이 브라우저에만 남는다
- 큰 파일은 읽는 데 1분 넘게 걸린다. 진행 표시가 뜨고, 끝나면 ②가 열린다

넣고 나면 열 이름·채워진 칸·평균 글자 수만 먼저 보여 준다.

### ② 설정

| 항목 | 뜻 |
|---|---|
| 글 열 * | 발언·댓글 본문이 든 열. 평균 길이가 너무 짧으면 경고가 뜬다(번호·이름 열을 고르면 숫자끼리 묶인다) |
| 집단 열 * | 비교할 집단(정당·채널·위원회 등). 보고서는 집단마다 누가 빠졌는지 잰다 |
| 작성자·발언자 열 | 있으면 「소수 집중」(몇 사람이 판을 채우나)을 잰다 |
| 대표 발언 옆에 붙일 열 | 날짜·위원회 등 맥락 |
| 공개판에 원문을 실을까 | **싣지 않음**(기본) / **원문만**(작성자 없이 — 공개 토론·청원·공개 댓글 등, 약관·저작권·개인정보는 직접 확인) / **실음**(공인의 공개 발언 — 대표 발언과 이름) |

**더 보기 — 세부 설정**

| 항목 | 기본 | 뜻 |
|---|---|---|
| 집단마다 최대 건수 | 0(전부) | 집단마다 무작위 표본. 큰 자료는 1,000~2,000. 보고서에 표본이라고 찍힌다 |
| 이보다 짧은 글은 뺌 | 5자 | 이보다 짧은 글은 뺀다. 0이면 안 뺀다 |
| 임베딩에 쓸 앞부분 글자 수 | 400 | 줄이면 빨라진다(240자 안팎이면 약 2배) |
| 열 값으로 빼기 | — | 예: 국회 자료의 `side` 열에서 「정부·기관·증인 등」을 빼 의원 발언만 |
| 이보다 작은 집단은 「기타」로 | 0 | 이보다 적은 집단은 「기타」로 |
| 묶음 고르기 / 최소 묶음 크기 | eom / 자동 | 주제를 크게(eom) 또는 잘게(leaf). 자료가 작으면 leaf |

자료가 2만 건을 넘으면 경고가 뜬다. 노트북에서는 몇 시간이 걸리고 메모리가 모자랄 수 있다.

### ③ 차수 — 돌리기

**1차는 규칙 없이 전부 묶는다.** 진행 패널에 단계(정리 → 임베딩 → 묶기 → 요약), 임베딩 건수와 남은 시간이 나온다.

- **시간** — 임베딩이 대부분이다. 사무용 노트북에서 초당 10건 안팎, 8만 건이면 2시간 넘게 걸린다
- **멈추기** — 두 번 누르면 멈춘다. 그때까지 계산한 임베딩은 저장돼 있어 다시 돌리면 이어서 계산한다
- **다시 쓰기** — 계산한 임베딩은 모든 프로젝트가 함께 쓴다(`작업 폴더/_cache/embeddings`, 원문 없이 해시와 숫자만). 같은 글이면 다시 계산하지 않는다
- 창을 닫아도 작업은 계속된다

끝나면 차수 카드에 **결과 보기**(공개판 · 내부 검토판)와 **다음 단계**(이 차수 판단하기) 버튼이 뜬다.

### ④ 판단

묶음마다 대표 발언과 무작위 표본을 읽고(「글 더 보기」로 그 묶음의 글을 더 읽는다)

- 공론이 아닌 묶음(의사진행·인사·광고 등)에 **「공론 아님 — 빼기」**
- **주제 이름**을 적는다

채점자 이름을 적고 **「내 판단 저장」**. 채점자가 둘 이상이면 일치도(κ)가 바로 나온다. 「**합의된 이름을 보고서에 넣기**」를 누르면 그 차수 보고서에 주제 이름이 들어간다.

### ⑤ 규칙

**「규칙 초안 만들기」** — 합의된 「빼기」 묶음에서 그 묶음에만 자주 나오는 문구를 찾아 패턴(정규식) 초안을 쓴다. 사람이 읽고 고치고 더한 뒤 **「r2.json으로 저장 → 2차에 쓰기」**. 그다음 ③에서 2차를 돌린다. 3차, 4차 … 횟수 제한은 없다. 각 보고서가 앞 차수 사슬을 기록한다.

### ⑥ 결과 보기

**2차·3차는 필요할 때만 돌린다. 언제 멈추든 마지막 차수의 보고서가 결과다.**

| 파일 | 무엇 | 밖으로 |
|---|---|---|
| `rounds/rN_public.html` · `.json` | **공개판** — 공론 지도, 주제, 집단별 빠짐, 흔들림, 소수 집중, 설정 전부. 원문은 ②의 선택만큼만 | 보내도 된다 |
| `rounds/rN_INTERNAL_do-not-share.html` · `.json` | **내부 검토판** — 표본 원문과 작성자 | **보내지 않는다** |

보고서 지도에서 「주제 / 안정도 / 집단 강조」로 색을 바꾼다. 집단이 많으면 「집단 강조」를 눌러 전체 목록에서 고르거나 찾는다.

## 4. AI 앱에 붙이기 (선택) — MCP

설정 페이지의 앱 탭(Claude Code · Cursor · VS Code · Windsurf · Gemini CLI · Codex CLI · LM Studio · LibreChat · Claude 데스크톱)에서 「**등록**」을 누르면 그 앱 설정에 서버 셋이 들어간다. 원래 설정은 백업하고, 다른 서버는 건드리지 않는다. 직접 붙여 넣을 설정도 함께 보여 준다. LibreChat은 `librechat.yaml`에 붙여 넣는다.

| 서버 | 하는 일 |
|---|---|
| `listen-check` | 이 도구 — 대화에서 진단을 돌리고 결과를 읽는다 |
| `ledger` | 초고의 수치·금지 문장 검사 |
| `survey-template` | 분모 규약을 박은 서베이 조회 틀 |

서버는 대화에 **집계만** 돌려준다. 원문은 PC의 내부 검토판에만 남는다. 자세한 설정은 [`servers/CONNECT.md`](../servers/CONNECT.md).

## 5. 명령줄

```bash
python install.py                    # 설치 + 시험
who-was-heard columns 자료.csv        # 열 이름만 본다
who-was-heard report 자료.csv --text 내용 --group 채널 --speaker 작성자 \
    --preset none --out 결과 --name r1 --cache 결과/cache
who-was-heard rules-draft --reviews A.json,B.json ...   # κ와 규칙 초안
who-was-heard report 자료.csv ... --preset 규칙.json --previous 결과/r1_public.json --name r2
who-was-heard label --reviews A.json,B.json ...          # 합의된 주제 이름 넣기
```

`who-was-heard <명령> --help`로 선택지를 본다. 미국 의회 예시는 [`examples/us-congress/`](../examples/us-congress/).

## 6. 문제가 생기면

| 증상 | 할 일 |
|---|---|
| 더블클릭해도 아무것도 안 뜬다 | `python start.py`로 켜서 창의 기록을 보거나 `_logs/start.log`를 연다. 파이썬이 PATH에 있는지 확인 |
| `/studio`가 「not found」 | 예전 서버가 켜져 있다. 「MCP 서버 끄기」 후 다시 켠다 |
| 고친 뒤 화면이 그대로 | 화면 파일(`.html`)만 바뀌었으면 F5. 파이썬 파일이 바뀌었으면 서버를 껐다 켠다 |
| 「정리 후 남은 글이 없습니다」 | 글 열을 맞게 골랐는지, 「이보다 짧은 글은 뺌」 기준이 너무 높지 않은지 본다 |
| 주제가 숫자·번호로 묶인다 | 글 열에 번호·ID 열을 골랐다. ②의 경고를 본다 |
| 임베딩이 너무 오래 걸린다 | 멈춘 뒤 「집단마다 최대 건수」나 「임베딩에 쓸 앞부분 글자 수」를 줄여 다시. 계산해 둔 것은 다시 쓴다 |
| 메모리 부족·작업이 죽는다 | 표본을 줄인다(2만 건 이하) |
| 유튜브 실시간 채팅이 안 받아진다 | 지금 방송 중인지, 키의 하루 할당량이 남았는지 |

## 7. 지우기

- 모델: 분석 화면 「임베딩 모델」 칸의 「모델 지우기」(두 번 누름)
- 작업: `문서\who-was-heard` 폴더를 지운다
- 앱 등록: 설정 페이지에서 「등록 취소」. 원래 설정 백업은 그 앱 설정 폴더에 남아 있다
- 도구: 저장소 폴더를 지운다. 패키지는 `pip uninstall who-was-heard sentence-transformers umap-learn hdbscan`
